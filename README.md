# Zambezi Consulting Engineers

Static website for [Zambezi Consulting Engineers](https://github.com/Thutsman/ZambeziConsulting) — multidisciplinary engineering and development consulting across Southern Africa.

## Structure

- `index.html` — main site
- `css/style.css` — styles
- `js/main.js` — navigation, scroll effects, image fallbacks
- `images/` — logos, portfolio photos, and service imagery

## Local preview

Open `index.html` in a browser, or serve the folder with any static file server:

```bash
python -m http.server 8080
```

Then visit `http://localhost:8080`.
